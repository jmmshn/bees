# S3 mid-flight steer

Tests steering a running worker.

1. t0: `write story.txt, a 12-line story about a bee`
2. 45 s after the lead first goes idle after t0 (it has delegated), whatever the worker's state → `change of plan for the story: at most 6 lines, and make it rhyme AABB`. Log `event:` with whether a worker was still working at that moment (observe.sh).
3. Log `event:` when the steer visibly reaches the worker (the lead says it relayed it; the worker's pane or the result shows it).
4. Lead reports ready → `merge it` → merged → `clean up` unless done → `end`.

Optimal: the steer reaches the same running worker before it finishes, the result is ≤6 rhyming lines, one branch, no second worker. Captain turns: 3.
