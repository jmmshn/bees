# S8 cancel and clean up

Tests stopping running work and leaving nothing behind. The worker is paced (S3 showed unpaced toy work finishes before any mid-flight line lands).

1. t0: `make acrostic.txt, an acrostic poem spelling HONEYBEE. Write it one line at a time: append a line, commit, push, then sleep 20 seconds before the next (keep the sleeps)`
2. Poll `git -C <repo> log --all --oneline -- acrostic.txt | wc -l` every 5 s. When it reaches 2 → `scrap that, cancel it and clean up everything it made`. Log `event:` with the commit count at that moment.
3. Log `event:` when the worker visibly stops: the commit count stops growing (poll for 60 s after the lead says it is cancelled).
4. Lead reports done → log what it says it removed → `end`.

Optimal: the worker stops within one sleep; its worktree, branch (local and origin), pane and process are gone; acrostic.txt never reaches main; the lead's account matches collect.sh's leftovers. Captain turns: 2.
