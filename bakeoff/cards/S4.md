# S4 conflict

Tests a merge conflict between two workers on the same file.

1. t0: `two separate tasks, one worker each: add teal to colors.txt, and add amber to colors.txt. Keep the file sorted.`
2. Lead reports both ready (or one) → `merge the teal one first`.
3. Merged → `now merge the amber one`.
4. Expect a conflict. Let the lead handle it; log `event:` for who resolved it (lead itself, the worker, or you) and how.
5. Both merged → `clean up` unless done → `end`.

Optimal: second merge conflicts or is detected as stale → lead has the amber worker merge main and resolve → lead re-checks (sorted, no markers) → merge → cleanup. Captain turns: 3–4, interventions: only merge `!` lines.
