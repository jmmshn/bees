# S5 blocked on the captain

Tests whether a worker's question reaches the captain.

1. t0: `rename the pets in pets.txt to my preferred naming style`
2. Do **not** volunteer the style. When the lead (in its own pane) asks you which style, answer `Title Case` (captain line), and log `event: question surfaced` first.
3. If a worker asks in its own pane but the lead never surfaces it: the stall rule applies (5 min idle → `status?`; 3 more → look at the worker pane). Log `event: question only in worker pane` if you find it there.
4. Lead reports ready → `merge it` → merged → `clean up` unless done → `end`.

Optimal: worker asks the lead, lead asks the captain within a minute of the worker starting, the answer is relayed, result is "Fluffy / Mr Whiskers / Rex The Dog / Sir Hops A Lot". Captain turns: 3.
