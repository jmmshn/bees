# toy repo

A toy repo for scripted bake-off runs. Keep changes small and only touch what the task names.

- `origin` is a local bare repo; there is no GitHub and no PRs.
- Do work on your own branch. Instead of a PR: commit, `git push origin <branch>`, and report the branch and commit sha.
- Only the captain decides merges. When the captain says merge: `git checkout main && git merge --no-ff <branch> && git push origin main`.
